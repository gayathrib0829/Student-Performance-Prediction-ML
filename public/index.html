SHAP Global Model Interpretability

While LIME explains individual student predictions (local), SHAP (SHapley Additive exPlanations) provides a global perspective on how features impact the overall Ensemble Voting Regressor across the entire dataset. It distributes credits fairly among all features based on game theory.

For Dataset 1, Previous Scores accounts for approximately 62% of the model's overall prediction power, followed by Hours Studied. Other variables like Sleep Hours or extracurricular activities show negligible global influence.
